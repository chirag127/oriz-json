This page is about oriz-json. The actual tool lives at json.oriz.in.

What it is

oriz-json is a client-side JSON workbench: paste, drop a file, or load a sample, then format, validate, explore, query, diff, and convert — with an optional AI assist. Nothing is uploaded; everything runs in the tab.

Key features

  • Format / minify / validate — 2/4/tab indent, minify, live line:col errors + byte/node/key/depth stats.
  • Tree viewer — collapsible tree, expand/collapse-all, per-node expand, syntax-colored values.
  • JSONPath query — run $..author-style expressions via jsonpath-plus.
  • JSON ↔ CSV — array-of-objects to CSV (union columns, RFC quoting) and CSV to JSON (typed coercion).
  • Diff — deep structural diff with add/remove/change summary and per-path detail.
  • Sort keys — recursive A→Z / Z→A.
  • AI assist (optional) — explain structure, infer a JSON Schema, or generate sample JSON.

Tech

  • Client-only Astro static site + a small React island; Tailwind v4.
  • Optional g4f AI via @chirag127/oz-ai — no API key.
  • PWA-installable; heavy libs dynamically imported per feature.
  • 100% in-browser — no upload, no signup, free, MIT-licensed.
